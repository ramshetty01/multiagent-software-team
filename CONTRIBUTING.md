# Contributing

## Local Checks

```sh
scripts/self_check.py
python3 -m pytest
```

## Pull Requests

- Keep changes scoped to one issue.
- Include validation commands in the PR body.
- Do not commit secrets, run artifacts, or generated bytecode.
- Update docs when changing CLI, configuration, architecture, or security behavior.

## Design Changes

For changes to orchestration, sandboxing, model providers, or the task-board
contract, add or update an ADR under `docs/adr/`.
